## About

I design and build **multi-agent systems**: agents that break down goals, pick the right tools, remember what matters, and run safely on a user's own machine. I care most about the unglamorous parts that decide whether an agent is actually usable: token cost, latency, context quality, and security.

I'm open to **AI Engineer / Product Developer** roles in agentic AI, applied ML systems, and developer infrastructure.

<br/>

## What I focus on

<table>
  <tr>
    <td width="33%" valign="top">
      <h3>🧠 Agent Orchestration</h3>
      Master-worker patterns, parallel delegation, and stateful agent workflows that scale past a single prompt.
    </td>
    <td width="33%" valign="top">
      <h3>⚡ Context & Tooling</h3>
      Dynamic tool loading, hybrid retrieval (BM25 + embeddings), and context compaction to cut token waste.
    </td>
    <td width="33%" valign="top">
      <h3>🔒 Safe Local Execution</h3>
      Local-first runtimes, filesystem boundary hardening, and bring-your-own-key designs that keep users in control.
    </td>
