## 👋 About Me

I'm a B.Tech Computer Science student (IBM Advanced Specialization) at **Medicaps University, Indore**, building **autonomous multi-agent systems** and the infrastructure that makes agents fast, cheap, and safe to run.

- 🤖 Building **Oreca.AI**, a multi-agent execution harness (private)
- ⚡ Obsessed with **token economics**, **dynamic tool loading**, and **context engineering**
- 🔒 Designing **local-first, security-conscious** AI tooling
- 🌱 Currently exploring: LangGraph, A2A protocol, agent evals & observability
